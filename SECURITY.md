# Security Policy

## Supported Versions

Only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly.

**Please DO NOT file a public issue for security vulnerabilities.**

Instead, please report them via email to: **vitiportelada@gmail.com**

## Response SLA

- **Initial Response**: Within 48 hours of report acknowledgment
- **Fix Timeline**: We will work with you to determine the best course of action and timeline for a fix

## Information to Include

When reporting a vulnerability, please include:

1. Type of vulnerability
2. Full paths of source file(s) related to the vulnerability
3. Location of the affected source code (tag/branch/commit or direct URL)
4. Step-by-step instructions to reproduce the issue
5. Proof-of-concept or exploit code (if possible)
6. Impact assessment and potential attack scenarios

We will endeavor to acknowledge your report within 48 hours and will keep you informed of the progress toward a fix.
